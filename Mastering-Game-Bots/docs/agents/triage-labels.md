# Triage labels

| Canonical role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Missing information |
| ready-for-agent | ready-for-agent | Specified and authorized for agent work |
| ready-for-human | ready-for-human | Requires student action or judgment |
| wontfix | wontfix | Rejected or redundant |

Each active, triaged ticket has exactly one status and one category
(`bug` or `enhancement`). Keep claim and resolution metadata separate.
For triage-generated tickets and comments, use the AI disclaimer required
by the triage skill.

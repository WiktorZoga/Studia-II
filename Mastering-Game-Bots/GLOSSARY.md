# Soak Overflow

Vocabulary used when discussing the game and its input protocol.

## Language

**Agent**:
A unit on the game grid, with a unique ID and an owning player.
_Avoid_: AI assistant, programming agent when referring to a game unit.

**Player**:
One of the two sides in the match, each controlling its own team of agents.

**Turn**:
A game step in which each surviving agent receives actions and the game
resolves their effects.

**Wetness**:
The damage accumulated by an agent, reported as a value from 0 to 100.

# Mastering Game Bots

The main project is the [Soak Overflow C++20 bot](soak-overflow/README.md).
Its folder contains the source, a short strategy explanation, an optional CMake
build, game references, and [post-mortem research](soak-overflow/RESEARCH.md).

Course materials and development history remain outside the game project.
Start with `soak-overflow/README.md` to understand and run the bot.

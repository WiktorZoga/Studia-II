# Statusy triage

W lokalnych zgłoszeniach zapisuj wybraną rolę jako `Status: <rola>`.

| Rola | Status | Znaczenie |
| --- | --- | --- |
| needs-triage | needs-triage | Wymaga oceny |
| needs-info | needs-info | Wymaga dodatkowych informacji |
| ready-for-agent | ready-for-agent | Sprecyzowane, gotowe do pracy agenta |
| ready-for-human | ready-for-human | Wymaga pracy człowieka |
| wontfix | wontfix | Nie będzie realizowane |

Gotowość dla agenta nie znosi zasad wspólnej nauki z `AGENTS.md`.

# Notatki z kursu

Tu trzymaj notatki i wyjaśnienia przydatne w całym przedmiocie, a nie tylko
przy jednym zadaniu. Materiały odnoszące się do konkretnego zadania zostaw
w katalogu jego listy, np. `P1/`.

Możesz tworzyć osobne pliki Markdown według tematu, np. `tokenizacja.md` albo
`modele-jezykowe.md`. Zapisuj źródło i datę przy notatkach opartych na
zewnętrznych materiałach. Nie kopiuj tu całych treści wykładów bez potrzeby.

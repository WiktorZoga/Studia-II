# Projekty

Każdą większą pracę, która wykracza poza pojedynczą listę, umieszczaj
w osobnym, opisowo nazwanym katalogu, np. `analiza-korpusu/`. Zacznij od jego
README z celem, sposobem uruchomienia i odnośnikami do materiałów.

Nie przenoś tu kodu ani materiałów używanych przez listę — trzymaj je przy
właściwym `P#`, żeby kontekst zadania był czytelny.

# 02: Uzupełnienie własnych przykładów permutacji

**What to build:** Program pokazuje ranking dla zdań z polecenia oraz kilku
własnych przykładów, w tym multizbioru z powtarzającym się słowem.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Są przynajmniej trzy własne przykłady o małej liczbie słów.
- [x] Jeden przykład zawiera powtórzone słowo.
- [x] Powtórzenia nie tworzą identycznych permutacji w wyniku.
- [x] Dotychczasowy algorytm i ranking pozostają bez przebudowy.
- [x] Krótka ręczna kontrola, bez oceniania wszystkich zdań modelem.

## Wynik

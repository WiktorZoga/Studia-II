# 01: Bezpieczny wybór odpowiedzi chatbota

**What to build:** Chatbot nadal wybiera krótką odpowiedź spośród kilku propozycji,
ale nie przerywa rozmowy, gdy wszystkie propozycje są puste po czyszczeniu.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Pusta lista propozycji daje prostą odpowiedź zastępczą.
- [x] Nieużywany fragment filtrowania jest usunięty.
- [x] Wybór według długości i historia rozmowy pozostają czytelne.
- [x] Weryfikacja obejmuje pustą i niepustą listę, bez długiej rozmowy z modelem.
- [x] Bez dodatkowych klas, frameworków i infrastruktury testowej.

## Wynik

Sprawdzono pustą listę i wybór spośród niepustych propozycji bez ładowania modelu.

Końcowy przegląd Standards i Spec: brak nowych ustaleń wymagających poprawy.

# Instrukcje dla Modele-Jezykowe

Obowiązują również zasady z nadrzędnego `../AGENTS.md`, w szczególności ochrona
materiałów i wspólna nauka. Poniższa konfiguracja dotyczy tylko tego przedmiotu.

## Agent skills

### Issue tracker

Zgłoszenia i specyfikacje zapisujemy lokalnie w `.scratch/`.
Przed pracą ze zgłoszeniami przeczytaj [issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

Domyślne role triage zapisujemy jako statusy w plikach zgłoszeń.
Przed triage przeczytaj [triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Układ single-context: `GLOSSARY.md` i `docs/adr/` w katalogu tego przedmiotu.
Przed pracą z dokumentacją domeny przeczytaj [domain.md](docs/agents/domain.md).
